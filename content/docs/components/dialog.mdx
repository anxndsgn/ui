## Props

### DialogContent

| Prop              | Type      | Default | Description                              |
| ----------------- | --------- | ------- | ---------------------------------------- |
| `showCloseButton` | `boolean` | `true`  | Renders the top-right close button.      |
| `overlayProps`    | `object`  | -       | Props forwarded to the backdrop element. |
| `className`       | `string`  | -       | Adds custom classes to the dialog popup. |

### DialogFooter

| Prop              | Type      | Default | Description                      |
| ----------------- | --------- | ------- | -------------------------------- |
| `showCloseButton` | `boolean` | `false` | Appends an outline close button. |
