## Props

### NumberField

| Prop           | Type                        | Default     | Description                       |
| -------------- | --------------------------- | ----------- | --------------------------------- |
| `size`         | `"sm" \| "default" \| "lg"` | `"default"` | Controls the height of the group. |
| `value`        | `number`                    | -           | Controlled value.                 |
| `defaultValue` | `number`                    | -           | Initial value when uncontrolled.  |
| `min` / `max`  | `number`                    | -           | Allowed range.                    |
| `className`    | `string`                    | -           | Adds custom classes to the root.  |

### NumberFieldScrubArea

| Prop    | Type     | Default | Description                              |
| ------- | -------- | ------- | ---------------------------------------- |
| `label` | `string` | -       | Label rendered next to the scrub cursor. |
