## Props

| Prop           | Type                         | Default        | Description                      |
| -------------- | ---------------------------- | -------------- | -------------------------------- |
| `value`        | `number \| number[]`         | -              | Controlled value or range.       |
| `defaultValue` | `number \| number[]`         | `min`          | Initial value when uncontrolled. |
| `min` / `max`  | `number`                     | `0` / `100`    | Bounds of the track.             |
| `orientation`  | `"horizontal" \| "vertical"` | `"horizontal"` | Direction of the track.          |
| `className`    | `string`                     | -              | Adds custom classes to the root. |
