## Props

### PopoverContent

| Prop          | Type                                     | Default    | Description                            |
| ------------- | ---------------------------------------- | ---------- | -------------------------------------- |
| `side`        | `"top" \| "bottom" \| "left" \| "right"` | `"bottom"` | Preferred side of the trigger.         |
| `sideOffset`  | `number`                                 | `6`        | Pixel offset from the trigger.         |
| `align`       | `"start" \| "center" \| "end"`           | `"center"` | Alignment relative to the trigger.     |
| `alignOffset` | `number`                                 | `0`        | Pixel offset along the alignment axis. |
| `className`   | `string`                                 | -          | Adds custom classes to the popup.      |
