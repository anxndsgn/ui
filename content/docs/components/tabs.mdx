## Props

### TabsList

| Prop        | Type                                | Default     | Description                       |
| ----------- | ----------------------------------- | ----------- | --------------------------------- |
| `variant`   | `"default" \| "line"`               | `"default"` | Visual treatment of the tab list. |
| `size`      | `"xs" \| "sm" \| "default" \| "lg"` | `"default"` | Height and text size.             |
| `className` | `string`                            | -           | Adds custom classes to the list.  |

### TabsTrigger

| Prop        | Type     | Default | Description                              |
| ----------- | -------- | ------- | ---------------------------------------- |
| `value`     | `string` | -       | Value that activates the matching panel. |
| `className` | `string` | -       | Adds custom classes to the trigger.      |
