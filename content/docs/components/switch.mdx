## Props

| Prop              | Type                | Default     | Description                              |
| ----------------- | ------------------- | ----------- | ---------------------------------------- |
| `size`            | `"default" \| "sm"` | `"default"` | Controls the track and thumb size.       |
| `checked`         | `boolean`           | -           | Controlled checked state.                |
| `defaultChecked`  | `boolean`           | -           | Initial checked state when uncontrolled. |
| `onCheckedChange` | `function`          | -           | Called with the next checked state.      |
| `className`       | `string`            | -           | Adds custom classes to the switch.       |
