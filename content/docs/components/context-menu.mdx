## Props

### ContextMenuContent

| Prop          | Type                                     | Default   | Description                            |
| ------------- | ---------------------------------------- | --------- | -------------------------------------- |
| `side`        | `"top" \| "bottom" \| "left" \| "right"` | `"right"` | Preferred side of the cursor.          |
| `align`       | `"start" \| "center" \| "end"`           | `"start"` | Alignment along the chosen side.       |
| `sideOffset`  | `number`                                 | `0`       | Pixel offset from the cursor.          |
| `alignOffset` | `number`                                 | `4`       | Pixel offset along the alignment axis. |
| `className`   | `string`                                 | -         | Adds custom classes to the popup.      |
