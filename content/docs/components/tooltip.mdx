## Props

### TooltipProvider

| Prop    | Type     | Default | Description                           |
| ------- | -------- | ------- | ------------------------------------- |
| `delay` | `number` | `200`   | Delay in milliseconds before showing. |

### TooltipContent

| Prop         | Type                                     | Default    | Description                        |
| ------------ | ---------------------------------------- | ---------- | ---------------------------------- |
| `side`       | `"top" \| "bottom" \| "left" \| "right"` | `"top"`    | Preferred side of the trigger.     |
| `sideOffset` | `number`                                 | `4`        | Pixel offset from the trigger.     |
| `align`      | `"start" \| "center" \| "end"`           | `"center"` | Alignment relative to the trigger. |
| `className`  | `string`                                 | -          | Adds custom classes to the popup.  |
