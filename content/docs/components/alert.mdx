## Props

| Prop        | Type                                      | Default     | Description                                 |
| ----------- | ----------------------------------------- | ----------- | ------------------------------------------- |
| `variant`   | `"default" \| "warning" \| "destructive"` | `"default"` | Controls the tone of the callout.           |
| `className` | `string`                                  | -           | Adds custom classes to the alert container. |
